用户确认“剩余攻略一起处理了”“可以，执行”“开始执行”。本批包含原有三篇图文样板、剩余 45 篇攻略，以及已批准的作物筛选/图形对比、鱼类时间输入、社区中心组合筛选、礼物查询说明。

- 保持 48 篇文章的 slug、分类、封面和路由；不新增攻略页凑数量。

## 编辑与验收方法

1. 三组各核对 15 篇非样板攻略，保留有效原文、数字表与站内入口，修正事实冲突；专题作为导航，不复制同一完整教程。
2. 使用原创流程/时间/材料示意，明确非游戏截图；真实工具截图与现有界面同步。
3. 每幅图具有尺寸、替代文字、懒加载、图注和原图链接；正文保留可核查来源。
4. 通过文章 API 和服务端 HTML 两条路径检查图文，逐图校验实际资源与声明尺寸；检查全部攻略站内链接。
5. 全量测试、构建、差异复查后才推送；生产备份、旧镜像回滚点就绪后部署。
